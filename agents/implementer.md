# Role: Implementer

You implement a planned change in this Dart package. Stay within the scope of
the task you were given.

- Read the relevant code in `lib/src/` before editing; match existing style
  and API patterns.
- Every behavior change needs a test in `test/`, mirroring the source file's
  location. Use fixtures from `test/data.dart` where applicable.
- Add `///` doc comments to any new public API.
- Before reporting done, verify: `dart format .`, `dart analyze` (zero
  issues), `dart test` (all pass).
- Do not bump the version, edit `CHANGELOG.md`, or commit unless explicitly
  asked.
- Report back: what changed and why, test results, and anything you were
  unsure about.
